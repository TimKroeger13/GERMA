GERMA Tutorial

Was ist das GERMA-Tool?

Das GERMA-Tool ist eine Applikation, die eine schnelle geothermische Potenzialanalyse für Erdwärmesonden für ein oder mehrere Flurstücke im Land Berlin-Brandenburg erstellen kann.

Das Tool berechnet dabei, welche Flächen für geothermische Bohrungen nach den offiziellen Abstandsregelungen des Berliner Senats geeignet sind, und modelliert bei Bedarf für diesen Bereich eine optimale technisch und rechtlich maximal mögliche Auslegung geothermischer Sonden bei einem Sondenabstand von 6 Metern.

Für die gewählte Fläche und die modellierten Sonden werden die wichtigsten geothermischen Parameter berechnet
Tiefenbegrenzungen werden ebenfalls berücksichtigt und in die Berechnung einbezogen. Dazu wird für die modellierte Sondenkonstellation wird außerdem der Gesamtentzug aller Sonden berechnet, wobei die gegenseitige Beeinflussung im Erdreich ebenfalls Beachtung findet.

Das GERMA-Tool befindet sich derzeit in der ersten Prototypenphase und ist online geschaltet.
Wir freuen uns über Ihr Feedback sowie über Feature- und Bug-Tickets.


Bitte beachten Sie, dass der generierte Grundlagenbericht zur Nutzung von Erdwärmesonden am ausgewählten Standort keine Gewähr auf Richtigkeit und/oder Vollständigkeit bietet.
Die Nutzung und/oder Weitergabe der Angaben und Daten erfolgt auf eigenes Risiko.
Grundsätzlich ist für geothermische Kundenanfragen stets die Fachplanung O-GT-T zuständig und durch den Vertrieb einzubeziehen.

Wie kann ich das Tool benutzen?

Das Tool ist unter der folgenden Website erreichbar:
https://germa-tool.gs-local.germa.de/

Zugriff auf das Tool haben alle Mitarbeitenden der XXX-Gruppe. Sie können auf die Website zugreifen, solange Sie sich im internen Netz der XXX befinden.

Sollten Sie von einem externen Netz auf das GERMA-Tool zugreifen wollen, müssen Sie zunächst Ihren Azure VPN Client aktivieren.

Adresssuche

Das GERMA-Tool unterstützt die Adresssuche auf Basis der OpenStreetMap-Datenbank.

Um ein gewünschtes Grundstück zu finden, geben Sie einfach die Adresse in die oben angezeigte Adresszeile ein.

Je genauer die Adresse angegeben wird, desto höher ist die Wahrscheinlichkeit, dass diese korrekt erkannt wird.

Eine gute Adresssuche enthält idealerweise:
Straße + Hausnummer + Postleitzahl + Berlin

Nachdem Sie die Adresse eingegeben haben, bestätigen Sie diese entweder mit der "Enter"-Taste oder durch Klicken auf den "Suchen"-Button.

Grundstücke manuell auswählen

Alternativ können Sie Grundstücke auch direkt in der Karte auswählen.

Klicken Sie dazu einfach auf eine beliebige Stelle in der Karte, und das Tool identifiziert das dazugehörige Flurstück.

Erdwärmesonden modellieren

Wenn Sie ein Grundstück markiert haben, bietet Ihnen das Tool am Ende des Dialogs über den Button "Detailed Report" die Möglichkeit, Erdwärmesonden für das Grundstück zu modellieren.

Die Ausführung dieser Funktion kann etwas Zeit in Anspruch nehmen, da die Sonden berechnet werden. Besonders bei größeren Flächen kann die Rechenzeit ansteigen.

Nachdem das Sondenfeld modelliert wurde, wird Ihnen auf der Karte eine optimale Verteilung der Geothermie-Sonden entsprechend den geltenden Berliner Abstandsregeln angezeigt.

Zusätzlich wird der Report mit weiteren Informationen ergänzt. Dieser enthält unter anderem:
- Den Entzug für 2.400 Arbeitsstunden, der mit dem Sondenfeld bereitgestellt werden kann.
- Die Anzahl der Sonden sowie weitere Einschränkungen.

PDF erstellen

Oben rechts im Fenster-Dialog finden Sie einen Button mit der Bezeichnung "Print".

Wenn Sie diesen Button betätigen, wird der Inhalt des Fenster-Dialogs in eine PDF-Datei umgewandelt.

Es wird empfohlen, zuerst die Erdwärmesonden zu modellieren und anschließend den Bericht als PDF zu speichern, damit alle relevanten Informationen in der PDF enthalten sind.

Mehrere Grundstücke auswählen

Wenn Sie die "STRG"-Taste gedrückt halten, während Sie Grundstücke anklicken, können Sie die Flurstücke miteinander verknüpfen.

Alle Berechnungen werden dann für alle gewählten Flurstücke gemeinsam ausgeführt.

Bitte beachten Sie, dass Sie nur Flurstücke miteinander verbinden können, die sich topologisch berühren. Es ist nicht möglich, getrennte Flächen von Flurstücken auszuwählen. Wenn Sie zwei verschiedene Grundstücke auswerten möchten, müssen Sie dies nacheinander durchführen.

Bedenken Sie außerdem, dass die Modellierung von Erdwärmesonden bei größeren Grundstücken mehr Zeit in Anspruch nehmen kann.

Freie Gebietswahl

Das Tool bietet Ihnen zusätzlich die Möglichkeit, ein eigenes Gebiet zu wählen, falls Sie mit der Darstellung der Flurstücke nicht zufrieden sein sollten.

Klicken Sie dazu auf das kleine Viereck in der oberen linken Ecke des Tools.

Sobald Sie dies getan haben, befinden Sie sich im "Edit Mode". In diesem Modus können Sie durch Klicks den Umriss eines Grundstücks selbst zeichnen.

Wenn Sie mit dem gewählten Bereich zufrieden sind, klicken Sie auf den "Submit"-Button.

Optional können Sie für das gewählte Gebiet auch den Mindestabstand zur Außengrenze nicht berechnen lassen. Entfernen Sie dazu den Haken bei "Boundary" und klicken Sie erneut auf "Submit".

Um Ihre Auswahl zu löschen und den Edit Mode zu verlassen, klicken Sie auf das "X" links vom Submit-Button.
